# Meegle 只读访问

`lark-cli` 不提供 Meegle 工作项命令，不要用飞书 Wiki/Docs 命令猜测或拼接 Meegle API。

1. 优先使用当前环境已有的 Meegle 专用连接器或 CLI，以用户身份只读获取工作项正文、字段、附件和最新评论。
2. 没有专用能力时，使用已登录会话的浏览器打开用户提供的 Meegle 链接，读取页面可见内容；需要登录时让用户通过官方页面完成登录。
3. 两种方式都不可用时，请用户导出工作项或粘贴正文/评论，并明确记录访问限制。

记录工作项 URL、标题、状态、更新时间、正文范围和所读取评论的时间。优先级为：用户本轮确认 > 最新有效评论 > 工作项正文 > 背景资料。只读访问，不修改状态、评论、负责人或附件。
