# 一、需求概述：

## 1.1项目背景：

根据客户侧的反馈，目前已经有竞品提出了即将上线开放平台的计划，功能上与我们之前规划的类似，就是可以让客户将其他船体清洗公司（含潜水员、机器人等）产生的清洗报告，在开放平台上传后，进行AI识别，以统一的标准判断海生物及船漆情况。

## 1.2 项目目标

本系统旨在实现以下核心目标：

- **为客户提供统一管理船体检测/清洗报告管理平台：**客户可以上传非纳百的检测/清洗报告，我们通过AI识别，以统一的标准来进行船体海生物/油漆情况判断，并整理归档到客户船队的对应船舶下，使得客户船舶的所有检测/清洗数据都可以在一个平台一站式查看。
- **为客户提供船舶漆况生命周期管理看板：**通过对于客户上传报告的解析，我们可以分析船舶的漆况生命周期，从而让客户直观的了解船舶的漆况变化，为客户船舶进入干船坞刷漆的时间决策提供理论依据。
- **为客户提供AI模型微调能力：**客户可以在我们分析的基础上进行模型微调，从而构建客户专属的个性化识别模型，更贴近客户的喜好，从而能给到客户更精准的数据来进行洗船决策。
- **为客户提供专业的清洗建议**：通过对于客户船舶的数据收集及分析，给到客户最准确的清洗建议，从而促使客户下单纳百洗船服务，提升公司营收。

## 1.3 项目范围

本系统主要针对新版dashboard开放平台相关功能，包括：

1. 报告上传及AI识别
2. AI识别标准微调
3. 清洗建议
4. dashboard首页改版

不包含：

- 纳百报告查看功能
- 纳百年度计划相关功能
